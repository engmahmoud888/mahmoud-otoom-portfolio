# Mahmoud Otoom — Executive Portfolio

Single-page executive magazine portfolio website.

## Publish with GitHub Pages
1. Create a new public repository (for example `mahmoud-portfolio`).
2. Upload `index.html` and the `assets` folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. Use the generated GitHub Pages URL in LinkedIn Contact info / Featured section.

## Content notes
- `300+ Projects & Delivery Engagements` is intentionally broader than `300 projects managed` to keep the statement professionally defensible.
- Contact phone is intentionally omitted from the public site version.
